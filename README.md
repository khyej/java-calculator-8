# java-calculator-precourse

## 문자열 덧셈 계산기
입력한 문자열에서 숫자를 추출하여 더하는 계산기를 구현한다.

### 핵심 기능
- [x] 문자열을 쉼표(,) 또는 콜론(:)을 구분자로 사용한다.
- [x] 앞의 기본 구분자(쉼표, 콜론) 외에 커스텀 구분자를 지정할 수 있다. <br>커스텀 구분자는 문자열 앞부분의 "//"와 "\n" 사이에 위치하는 문자를 커스텀 구분자로 사용한다.
- [x] 구분자를 기준으로 분리한 각 숫자의 합을 반환한다.


### 입출력
- [x] 문자열 입력 안내 문구를 출력한다.
   - 출력 : `덧셈할 문자열을 입력해 주세요.`  
- [x] 문자열을 입력받는다.
   - 입력 : 구분자와 양수로 구성된 문자열 ( 예시 : `1,2:3` )
- [x] 계산된 결과를 출력한다.
   - 출력 :  `결과 : 6`
  

### 예외처리
- [x] 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션을 종료한다.


### 설계
- 양수와 구분자만 입력받는다. (음수 및 구분자 외의 문자는 계산 불가)
- 공백의 경우 0으로 계산한다. (예시 : "" -> 0)
- 공백 및 커스텀 구분자 제어 문자("//","\n")는 커스텀 구분자로 지정할 수 없다.
- 커스텀 구분자를 지정했을 경우 기본 구분자는 사용 불가하다.
